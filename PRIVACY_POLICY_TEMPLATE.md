# TapCopy Privacy Policy

**Effective date:** [INSERT DATE]

TapCopy helps users copy visible text from their Android screen after they intentionally tap the TapCopy floating button.

## Screen capture and text recognition

TapCopy uses Android's AccessibilityService screenshot capability only after the user taps the floating TapCopy button. The captured image is processed locally on the user's device with an on-device text-recognition model.

TapCopy does not upload screenshots or recognized text to a server. A temporary screenshot file is stored in the app's private cache and deleted when the text-selection screen closes.

## Accessibility API usage

TapCopy uses the AccessibilityService API to:

- display a user-controlled floating button over other apps; and
- take a screenshot after the user explicitly taps that button.

TapCopy does not use the AccessibilityService API to read passwords, retrieve the accessibility node tree, automate actions, type text, change device settings, or initiate actions without the user's request.

## Data collection

The MVP does not collect, sell, share, or transmit personal data, screenshots, recognized text, advertising identifiers, contacts, location, or browsing history.
